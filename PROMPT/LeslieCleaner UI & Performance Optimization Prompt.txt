# LeslieCleaner UI & Performance Optimization Prompt
## 模块名称
Global UI Redesign + Performance Optimization + Final Release Optimization

本次任务目标：

在保持 LeslieCleaner 全部功能完整的前提下，对整个软件进行一次商业级 UI 重构，并在项目开发完成后执行最终性能优化与发布前瘦身，最终达到国际一线商业软件的视觉品质、运行效率和发布质量。

======================================================================
第一部分：全局 UI 重构（Global UI Redesign）
======================================================================

【设计目标】

将 LeslieCleaner 当前整体偏深色、偏沉重的 UI 风格，升级为：

现代、高级、专业、轻盈、具有高级质感的白色主题（Premium Light Theme）。

Apple × Microsoft Fluent 2 × Twitter(X) × Notion × Arc Browser × Raycast

✓ 干净
✓ 高级
✓ 专业
✓ 克制
✓ 通透
✓ 有呼吸感
✓ 有层次感
✓ 有品质感
