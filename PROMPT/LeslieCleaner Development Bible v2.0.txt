# 二、重点：卸载残留极速扫描架构（必须严格实现）

禁止使用：

* 全盘递归扫描
* Directory.GetFiles("C:\", "*", AllDirectories)
* 逐文件字符串匹配
* 同步 IO 扫描

必须采用 Multi-Stage Residual Pipeline。

## Stage 1：安装数据库定位（<100ms）

扫描：

* HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall
* HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall
* MSI ProductCode
* Windows Installer Cache
* Winget Source
* Appx Package Database

输出：

* InstallLocation
* Publisher
* DisplayName
* ProductCode
* UpgradeCode
* InstallDate

## Stage 2：已知规则库定位（<300ms）

内置 ResidualRule.db。

示例：

```json
{
  "publisher": "Adobe",
  "paths": [
    "%ProgramFiles%\\\\Adobe",
    "%AppData%\\\\Adobe",
    "%LocalAppData%\\\\Adobe",
    "%ProgramData%\\\\Adobe"
  ],
  "registry": [
    "HKCU\\\\Software\\\\Adobe",
    "HKLM\\\\Software\\\\Adobe"
  ]
}
```

必须内置至少 1000+ 软件规则。

## Stage 3：安装日志定位（<500ms）

优先读取：

* MSI 日志
* Inno Setup 卸载日志
* NSIS 卸载日志
* Burn Bundle 日志
* Visual Studio 安装日志
* Adobe 安装日志

## Stage 4：Publisher 索引定位（<1s）

预构建 SQLite 索引：

```sql
CREATE INDEX idx_publisher ON file_index(publisher);
CREATE INDEX idx_product ON file_index(product_name);
```

## Stage 5：深度扫描（仅在必要时）

限制范围：

* Program Files
* Program Files (x86)
* AppData
* ProgramData
* Documents
* Desktop

禁止扫描：

* Windows
* WinSxS
* System32
* DriverStore
* pagefile.sys
* hiberfil.sys
