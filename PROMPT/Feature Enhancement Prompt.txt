# Feature Enhancement Prompt
## 模块名称
Startup Manager（启动项管理）

本次仅修改 Startup Manager 模块，不允许影响其他模块。

==================================================
功能目标
==================================================

重新设计 Startup Manager，使其能够区分：

① Windows 系统原生启动项（Microsoft System Startup）

② 第三方软件启动项（Third-party Startup）

避免用户误关闭 Windows 必要启动项导致系统异常，同时让用户更加方便管理自己安装的软件，提高开机速度。

这属于 LeslieCleaner 的核心设计原则，优先考虑安全性、可维护性和用户体验。

==================================================
设计原则
==================================================

启动项绝不能简单按照启动位置分类。

必须按照"来源(Source)"进行分类。

即：

Windows系统自身

↓

Microsoft官方组件

↓

OEM厂商组件（联想、戴尔、惠普、华硕等）

↓

驱动程序

↓

用户安装的软件

↓

未知来源

==================================================
最终目标
==================================================

Startup Manager 不再只是"启动项列表"。

而是一个具有：

- 自动分类
- 微软系统保护
- 用户软件集中管理
- AI 启动优化建议
- 启动性能分析
- 风险预警
- 一键优化

能力的企业级启动项管理中心。

整个功能必须达到商业软件发布标准，代码可维护、可扩展、UI 与 LeslieCleaner 全局设计语言保持一致。
