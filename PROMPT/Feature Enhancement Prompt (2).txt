# Feature Enhancement Prompt
## 模块名称
Installer Experience + Batch Operation + UX Details Enhancement

本次任务仅增强 LeslieCleaner 的安装体验、批量操作体验以及整体交互细节，不修改已有业务逻辑，实现商业级软件应具备的用户体验。

======================================================================
一、自定义安装（Custom Installer）
======================================================================

当前安装器必须升级为商业软件安装器，而不是默认的一键安装。

必须支持：

✓ 自定义安装（Custom Installation）

✓ 快速安装（Express Installation）

默认进入：

快速安装

用户点击：

"自定义安装"

进入高级安装页面。

----------------------------------------------------------------------
安装目录
----------------------------------------------------------------------

必须允许用户自由选择安装目录。

例如：

默认：

C:\Program Files\LeslieCleaner

支持：

浏览(Browse)

新建文件夹

输入路径

记住上次安装位置

自动检测磁盘剩余空间

实时显示：

安装包大小

安装后预计占用空间

目标磁盘可用空间

若空间不足：

禁止安装。

提示：

"目标磁盘空间不足，请选择其他位置。"

----------------------------------------------------------------------
开始菜单
----------------------------------------------------------------------

支持：

☑ 创建开始菜单快捷方式

☑ 创建桌面快捷方式

☑ 固定到开始菜单（可选）

☑ 固定到任务栏（可选）

----------------------------------------------------------------------
开机启动
----------------------------------------------------------------------

安装过程中允许用户选择：

☑ 开机自动启动 LeslieCleaner

默认：

关闭。

避免影响系统启动速度。

----------------------------------------------------------------------
自动更新
----------------------------------------------------------------------

安装时允许用户选择：

☑ 启用自动更新（推荐）

默认开启。

支持后续关闭。

----------------------------------------------------------------------
卸载信息
----------------------------------------------------------------------

安装器必须自动注册：

Windows 卸载程序。

支持：

修改

修复

卸载

支持控制面板卸载。

支持 Windows 设置 -> 应用。

----------------------------------------------------------------------
安装完成
----------------------------------------------------------------------

完成页面：

☑ 立即启动 LeslieCleaner

☑ 打开使用指南

☑ 查看更新日志

默认：

立即启动。

======================================================================
最终目标
======================================================================

LeslieCleaner 的安装体验、批量操作和整体交互必须达到国际商业软件标准。

用户应能够：

✓ 自定义安装目录

✓ 自定义安装选项

✓ 自由选择是否创建快捷方式

✓ 自由选择是否开机启动

✓ 自由选择是否自动更新

同时，所有支持列表的数据页面都必须提供：

✓ 全选

✓ 取消全选

✓ 反选

✓ 三态复选框

✓ 高性能批量操作

最终让 LeslieCleaner 在安装体验、操作效率、易用性和细节打磨方面全面超越同类 Windows 系统优化软件。
