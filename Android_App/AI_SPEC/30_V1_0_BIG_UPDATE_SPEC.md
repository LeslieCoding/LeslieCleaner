# LeslieCleaner Android 1.0.0 大版本规格

## 用户目标

来源：USER_EXPLICIT。保持当前 UI 视觉不变，把现有单点扫描基础升级为可解释、可追踪、可复核的设备只读分析版本。

## 范围

### 本版本包含

- 将应用扫描结果扩展为系统应用、用户应用、启用状态、可调试状态等分类数据。
- 扫描结果显示分类摘要，保留现有应用名称与版本列表。
- 为扫描记录补充版本、耗时和分类摘要，仍只保存脱敏事实。
- 保持 200 条审计上限、FileProvider 导出边界和无运行时权限。
- 将 Android 应用版本提升为 1.0.0 / versionCode 2。

### 明确不包含

- 删除应用、删除文件、清理缓存或任何默认修改设备数据的行为。
- Root、隐藏 API、远程 AI、后台常驻和生产发布。
- 改变现有 UI 视觉体系、导航结构和中文界面要求。

## 需求与验收

| ID | 来源 | 验收 |
|---|---|---|
| R-101 | USER_EXPLICIT | 首页扫描仍可执行，并显示真实的分类摘要 |
| R-102 | AI_RECOMMENDED | 每个应用条目保留包名身份、名称、版本、系统/用户、启用/调试事实 |

## 任务树

- T-025：升级 PackageManager 读取模型与分类摘要
- T-026：升级审计记录契约并保持旧 JSONL 可读
- T-027：接入结果摘要和证据展示，不改变 UI 视觉骨架
- T-028：升级版本号、测试和设备回归

## 1.1.0 延续任务

- T-029：应用清单搜索、用户/系统筛选和单应用详情
- T-030：长列表虚拟化、可访问性语义、构建与设备回归

## 风险与恢复点

- 风险：R2；涉及扫描模型与本地审计格式，但不删除用户文件。
- 恢复点：本次修改前的 Android_App 源码与 `app-debug.apk` 0.1.0。
- 回滚：还原本版本变更文件，恢复 versionCode 1/versionName 0.1.0；旧 JSONL 字段保持兼容。

## 1.2.0 延续任务

- T-033：根据公开 PackageManager 事实扩展目标 SDK、最近更新时间与可解释的关注提示。
- T-034：将版本、更新时间、启用状态与调试标记纳入脱敏快照差异判断。

明确边界：关注提示只描述公开 API 观察到的构建或运行状态，不输出恶意判定、不执行删除、不新增权限。
