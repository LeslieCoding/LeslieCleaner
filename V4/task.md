# Task: Implement a feature to allow users to customize their dashboard layout.

## Requirements:
- Users should be able to rearrange dashboard widgets.
- Users should be able to add and remove widgets.
- Dashboard layout should be saved and persisted.
- A preview mode should be available before applying changes.

## Constraints:
- Use React for the frontend.
- Use a drag-and-drop library like `react-grid-layout`.
- Backend should be implemented in Node.js/Express.
- Use MongoDB for persistence.
- The dashboard layout should be responsive.
