## 数据呈现约束

- 回收站存在 Shell 服务时只采用 Shell 的逻辑项目数/字节数；没有 Shell 服务时回退目录枚举并且不得宣称为全系统逻辑计数。
- 扫描结果必须同时呈现项目数、字节数、错误数和取消状态；`ErrorCount > 0` 时 UI 不得显示“完整扫描”。
- 注册表发现项不伪造大小，统一显示为 0 字节并用单独项目数统计。
