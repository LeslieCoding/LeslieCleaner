## 1. 规范差距与实现结果

### 1.1 平台中心与真实状态

- 平台中心统一提供 AI、插件、更新与安全状态入口，并绑定真实服务；AI 支持请求取消和离线降级，插件启用前展示发布者与权限，更新失败有可行动错误，安全中心展示得分、只读状态与原因。
- 新增匿名 CPU/内存/磁盘系统上下文提供器；不把个人文件内容作为 AI 上下文。
- 完整性安全不再让新安装永久停留在只读：用户必须经过两次明确确认，才会对已核验安装文件建立/重建可信基线。界面明确说明系统绝不会自动把当前文件标记为可信。
- 基线严格覆盖五类目标：启动器、核心库、运行配置、数据库组件、插件契约；缺失任一文件即拒绝建立。可信备份位于应用根目录之外。
- 从可信备份修复入口会先检查数据库/审计、权限安全探针、更新来源、插件验签与加密往返，再调用修复服务并重新评估；未满足条件时保持只读，不伪报恢复。

### 1.2 Smart Scan 双口径与诚实清理结果

- 总结果突出“预计可释放（磁盘占用）”，辅显 Shell/逻辑大小和项目数。
- 分类行显示：磁盘占用、逻辑大小、元数据、无法访问数量和统计来源。
- `MeasurementDiscrepancyBytes` 非零时明确显示“统计口径差异”，并解释可能来自扫描期间变化；没有隐藏两个统计来源之间的差异。
- 回收站进入清理确认前再次展示预计实际释放与 Shell 逻辑大小，并提示系统级清空不可还原。
- 清理结果只把引擎确认的 `FreedBytes` 作为实际释放；失败项不计为成功。
- 逐项失败被归类为：需要管理员权限、文件被占用、受系统/完整性保护、清理后复验失败或其他原始错误，并给出下一步。
- 清理后对所选分类真实复扫，显示剩余项目、剩余大小、无法确认位置；复扫失败时明确显示“无法确认”，不显示纯成功页。

### 1.3 启动项提权恢复

- `StartupChangeResult.RequiresElevation` 会进入单独的用户状态，明确说明项目尚未更改。
- 页面出现“以管理员身份重新启动并重试”入口，调用现有 `ElevationHelper.RestartAsAdmin()`，触发 Windows UAC 后整体重启应用。
- 确认文案明确这是整应用管理员重启，重启后仍须重试并复验；没有声称已实现按单项提权代理。
- 启动项操作栏改为可换行布局，降低高 DPI 和窄窗口下的重叠风险。

### 1.4 非技术用户、可访问性与非阻塞导航

- 主导航异步激活，旧页面激活可取消；代际校验防止旧请求覆盖新页面状态。导航繁忙、失败与恢复建议可见，不阻塞 UI 线程。
- 主窗口设最小可用尺寸、像素对齐；平台中心/Smart Scan/启动项采用纵向卡片和可换行操作区，避免固定双列在 200% 缩放下挤压。
- 添加系统高对比主题跟随、键盘焦点视觉；主要按钮、输入、列表、状态区域添加 AutomationProperties 与 LiveSetting。
- 平台中心关键动作提供中英 RESX；其余历史页面仍有硬编码中文，未声称完成全应用本地化。
- 蓝白主色、暖白背景、柔和主色卡片、统一圆角/阴影/间距延续现有 Fluent 视觉系统。

### 1.5 安装、升级与卸载

- Inno Setup 脚本支持当前用户/所有用户两种安装模式：`PrivilegesRequired=lowest` 与 `PrivilegesRequiredOverridesAllowed=dialog commandline`。
- 支持开始菜单、桌面快捷方式、自定义路径；拒绝磁盘根、Windows、System 与 ProgramData 等危险安装目录，并要求至少 512 MB 可用空间。
- 检测已有版本，安装前提示升级；按当前安装范围备份配置/数据，写安装日志，安装完成检查主程序存在。
- 卸载提供：仅卸载程序、保留数据；或删除当前安装范围内的应用数据。删除数据需要第二次确认，文案明确不会删除 LeslieCleaner 数据目录之外的个人文件。
- 自包含 win-x64 发布目录已经生成，安装脚本排除 PDB、XML、TRX 与测试文件。

以下项目没有测试证据，不能宣称已验收：

1. 2026-09-01 使用 Inno Setup 7.1.0 成功编译 `LeslieCleanerSetup-4.0.0.exe`，编译警告为 0；当前产物 SHA-256 为 `8B4C11AF61C7AC26C16FF0E92BA204BB4DBA828CC612F79FFD77AB57A657EFC0`，尚未进行发布者代码签名。
2. 当前用户静默安装、注册表页启动、静默卸载均退出 0；安装目录被移除，`ProgramData` 用户数据按策略保留，且 `BUILTIN\\Users` 对产品数据根目录获得可继承的 `Modify` 权限。尚未在干净虚拟机执行所有用户/UAC、覆盖升级、跨版本迁移、回滚和交互式“删除数据”卸载矩阵。
3. 没有人工视觉检查 100%/150%/200% DPI、超长文本、窄屏、多显示器、明暗/高对比实时切换；布局只完成代码/XAML级约束和编译验证。

6. 隐藏启动只持续 6 秒，不等价于性能、空闲内存或长期稳定性验收。
