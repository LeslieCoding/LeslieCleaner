## 3. 性能与稳定性实测

| 场景 | 样本 | 结果 |
|---|---:|---:|
| Smart Scan 真实全量 | 36,207 项 / 16,361.0MB | 1,474.60ms，满足 <5s |
| Registry 全规则 | 本机规则集 | 806.13ms，满足 <3s |
| Browser 真实扫描 | 7 项 | 229.76ms，满足 <2s |
| File index 全范围 | 31,703 项 | 3,432.73ms |
| File index 100k | 100,000 项 | 全扫 2,439.55ms；无变化增量 807.11ms |
| File index 500k | 500,000 项 | 16,414.20ms |
| Database 100k 写入 | 100,000 行 | 7,246.18ms |
| Database publisher 查询 | 100,000 行库 | 29.66ms |
| Duplicate Finder | 5,000 文件 | 3,050.31ms |
| Registry 读取 | 5,000 键 | 71.54ms |
| Quarantine | 1,000 文件 | 移入 34,571.42ms；恢复 5,447.23ms |
| Shredder DoD3 | 100MB | 392.3MB/s |
| 10 分钟 Soak | 1,844 次连续扫描 | 托管堆增长 -20.6MB，门槛 <60MB |

Soak 期间采样托管堆主要在约 14.7–42.2MB 区间；47 秒时一次 95.8MB 峰值随后回收，没有形成单调增长。该结论只针对托管堆和当前受控环境，不外推为应用空闲工作集已满足 <120MB。
