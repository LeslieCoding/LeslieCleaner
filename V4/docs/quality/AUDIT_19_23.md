# V4 规范对照审计：19–23

> 依据 19–23 号规范全文及 V4 源码。状态分为“已实现”“部分实现”“未实现”；只有行为测试与双轮全量回归通过才标记“已验收”。

## 19 启动项管理

已实现：注册表 Run、启动文件夹、计划任务、服务/驱动发现；MicrosoftSystem/UserApplication/Unknown 分类；发布者与签名信息；系统关键项保护；禁用、启用和 JSON 备份恢复；异步取消与日志。

缺口：Delayed 状态的创建/管理；启动耗时历史、趋势和报告；7 日缓存/增量刷新；基于 ETW/性能计数器的实际影响测量；分类和签名变化后的复核策略。结论：核心安全管理已实现，测量与历史闭环为 P1。

## 20 隐私保护

已实现：Chrome、Edge、Brave、Firefox、Arc、Opera、Vivaldi 多配置发现；浏览器运行检测；缓存隔离；Cookies/History/Downloads/FormHistory SQLite 安全处理；备份与回滚；白名单；明确不碰密码数据。

缺口：Keep All/Tracking Only/Selected 的跟踪 Cookie 分类策略；历史时间范围和自定义区间；会话数据独立确认；隐私评分与解释性建议；浏览器路径/版本增量缓存；浏览器数据库锁定和异常恢复的全矩阵验证。结论：多浏览器安全清理已实现，精细策略和评分为 P1。

## 21 文件分析

已实现：大文件 Top-N、类型统计、Treemap 数据与建议；重复文件 Size→Partial Hash→Full SHA-256 分级算法、流式读取、取消、图片相似度；有界通道文件索引、USN/增量、Watcher、SQLite、重解析点和受保护范围。

缺口：完整驱动器健康/存储统计 API；面向 UI 的全字段搜索过滤和分页；惰性目录树加载证据；30 日分析缓存和哈希复用策略；公开 `IAsyncEnumerable` 流式扫描契约。结论：核心算法已实现，查询体验和长期缓存为 P1。

## 22 备份与恢复

已实现：注册表键/值、文件、配置、数据库统一备份模型；完整复制/元数据/移动模式；索引、查询、SHA-256 验证、锁定与删除；Fail/Overwrite/Rename 冲突策略；恢复前当前状态备份；原子元数据/索引；年龄/数量/容量保留策略；审计。实现与边界见 `V4_BACKUP_RESTORE_REPORT.md`。

缺口：ZIP 流式压缩；SQLite Backup API 和每日计划；设置/规则/白名单的完整配置包；启动期 Recovery Mode；持久化 RestoreRecords 与用户报告；真实年龄/容量保留和提升权限注册表集成验证。结论：统一可逆备份核心已实现，灾难恢复编排为 P1。

## 23 AI 助手

当前基线仅有系统指标健康评分、三类规则建议和维护计划；不满足自然语言助手完整规范。

必须补齐：最小化聚合上下文采集；本地知识库；Provider 适配（本地优先、OpenAI-compatible 可选）；结构化 Prompt；危险请求安全过滤；自然语言问答；Storage/Performance/Startup/Privacy/Security 建议及优先级；隐私脱敏历史；Provider/模型/端点/温度配置与密钥非明文存储；超时、网络、无效响应和离线降级；请求/模型/耗时/错误日志。AI 只能解释、建议和协助，不得直接修改文件、注册表、安全软件或系统保护。

结论：23 为当前最大功能缺口，正在实现完整 P1 闭环。

## 当前门禁

- 所有扫描和动作支持取消、真实进度、结构化日志，不把模拟数据记为实测。
- 危险动作必须有风险说明、备份建议、明确确认，且最终仍由非 AI 的安全执行服务完成。
- 聚焦测试必须覆盖正常、拒绝、失败、取消、重复执行和隐私边界。
- 每轮模块完成后重新执行第一轮全量功能/异常/流程测试，以及第二轮性能/内存/安全/UI/长稳测试。
