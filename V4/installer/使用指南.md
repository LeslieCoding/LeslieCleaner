# LeslieCleaner 使用指南

版本 1.1.1 · AI Powered Windows Optimization Platform

## 快速开始

启动后进入**首页**：系统健康评分 + 存储/隐私/启动项/性能四项概览。
点击「刷新评估」重新扫描，或用快捷操作直达各功能。

## 功能导航

| 页面 | 用途 | 安全机制 |
|---|---|---|
| Smart Scan | 一键扫描 14 类系统垃圾（临时文件/缓存/日志等） | 删除进隔离区，30 天内可恢复 |
| 注册表清理 | 五类无效注册表项扫描与清理 | 清理前自动备份（reg.exe 导出），可一键还原 |
| 智能卸载 | 已装应用发现、卸载、五阶段残留扫描 | 残留删除进隔离区 |
| 启动项管理 | 四级分类（系统/驱动/第三方/未知）+ 签名验证 + 影响评估 | 备份式禁用，随时恢复 |
| 隐私保护 | 八类使用痕迹探测与清理 | 逐项可选 |
| 文件粉碎 | 不可恢复地删除敏感文件 | 覆写前二次确认 |
| 重复文件查找 | 部分哈希 + 全哈希 + 感知哈希三级比对 | 删除进隔离区 |
| 大文件分析 | 磁盘占用可视化定位大文件 | 只读分析 |
| 工具箱 | 计划任务/服务/文件索引等系统工具 | 危险操作均有确认 |
| 运行日志 | 日志查看/筛选/导出诊断报告 | — |
| 设置 | 主题（浅色/深色）、隔离区等配置 | — |

## 常见问题

- **清理后想恢复**：设置/隔离区中还原（默认保留 30 天）。
- **注册表清理出问题**：注册表清理页的备份记录中一键还原。
- **卸载残留误报**：残留按置信度分级，低置信度项默认不勾选。
- **启动项误禁用**：启动项管理页重新打开开关即可（备份式禁用，无破坏）。

## 反馈与诊断

运行日志页可导出诊断报告（zip：近 7 天日志 + 异常聚合 + 系统信息，无隐私字段）。
